# MIROIR Stylist MongoDB Atlas Setup Guide

This guide sets up MongoDB Atlas for the MIROIR AI Stylist V2.5 RAG flow.

The current implementation expects:

- MongoDB Atlas database
- Atlas Vector Search indexes
- Gemini API key
- Product embeddings generated by backend scripts
- Existing try-on feature kept unchanged

## 1. Create MongoDB Atlas Project

1. Go to MongoDB Atlas.
2. Create a new project, for example `MIROIR`.
3. Create a cluster.
   - Free tier is fine for development.
   - Use MongoDB Atlas, not local MongoDB, because this feature uses Atlas Vector Search.
4. Create a database user.
   - Username: any value, for example `miroir_user`
   - Password: save it securely.
5. Add your IP address to Network Access.
   - For development, use your current IP.
   - Avoid `0.0.0.0/0` unless you understand the risk.

## 2. Get MongoDB Connection String

In Atlas:

1. Click `Connect`.
2. Choose `Drivers`.
3. Copy the connection string.

It should look like:

```env
mongodb+srv://miroir_user:<password>@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority
```

Use a database name such as:

```env
miroir
```

## 3. Configure Backend `.env`

Open `backend/.env` and add:

```env
MONGODB_URI=mongodb+srv://miroir_user:<password>@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority
MONGODB_DB_NAME=miroir

GEMINI_API_KEY=your_gemini_api_key
GEMINI_EMBEDDING_MODEL=text-embedding-004
GEMINI_GENERATION_MODEL=gemini-1.5-flash

MONGODB_PRODUCT_VECTOR_INDEX=products_embedding_index
MONGODB_OUTFIT_VECTOR_INDEX=outfits_embedding_index
MONGODB_FASHION_RULE_VECTOR_INDEX=fashion_rules_embedding_index
```

Keep your existing try-on values:

```env
PIAPI_KEY=...
CLOUDINARY_CLOUD_NAME=...
CLOUDINARY_API_KEY=...
CLOUDINARY_API_SECRET=...
```

## 4. Create Collections

Create these collections in database `miroir`:

- `products`
- `product_review_summaries`
- `outfits`
- `fashion_rules`
- `user_fashion_memory`
- `fashion_feedback_events`

You can create them manually in Atlas UI or let MongoDB create them on first insert.

## 6. Generate Embeddings

From `backend`:

```bash
npm run embed:products
npm run embed:outfits
npm run embed:fashion-rules
```

These scripts:

- build embedding text
- hash the text
- skip unchanged records
- call Gemini Embeddings
- save `embedding`, `embeddingTextHash`, and `embeddingUpdatedAt`

Important:

- Product embeddings do not include reviews.
- Review summaries are loaded separately during recommendation.

## 7. Create Atlas Vector Search Indexes

After embeddings exist, create vector indexes in Atlas.

Go to:

```text
Atlas → Database → Search → Create Search Index → JSON Editor
```

### Product index

Collection: `products`

Index name:

```text
products_embedding_index
```

JSON:

```json
{
  "fields": [
    {
      "type": "vector",
      "path": "embedding",
      "numDimensions": 768,
      "similarity": "cosine"
    },
    {
      "type": "filter",
      "path": "price"
    },
    {
      "type": "filter",
      "path": "gender"
    },
    {
      "type": "filter",
      "path": "availability"
    },
    {
      "type": "filter",
      "path": "status"
    },
    {
      "type": "filter",
      "path": "occasionTags"
    }
  ]
}
```

### Outfit index

Collection: `outfits`

Index name:

```text
outfits_embedding_index
```

JSON:

```json
{
  "fields": [
    {
      "type": "vector",
      "path": "embedding",
      "numDimensions": 768,
      "similarity": "cosine"
    },
    {
      "type": "filter",
      "path": "gender"

```

### Fashion rule index

Collection: `fashion_rules`

Index name:

```text
fashion_rules_embedding_index
```

JSON:

```json
{
  "fields": [
    {
      "type": "vector",
      "path": "embedding",
      "numDimensions": 768,
      "similarity": "cosine"
    }
  ]
}
```

If Gemini changes embedding dimensions for your selected model, update `numDimensions` to match the saved embedding array length.

## 11. Common Problems

### `MongoDB is not configured`

Check:

```env
MONGODB_URI=
MONGODB_DB_NAME=
```

### `Gemini is not configured`

Check:

```env
GEMINI_API_KEY=
```

### Atlas Vector Search returns no products

Check:

- products have `embedding`
- vector index name matches `.env`
- products have `availability: "in_stock"`
- products have matching `gender`
- products have matching `occasionTags`
- product price is within budget

### Vector index dimension error

Check one embedded document:

```json
"embedding": [...]
```

Count the embedding array length and set the Atlas index `numDimensions` to the same value.

### Gemini returns unknown product IDs

The backend already retries once and then fails safely. This means grounding safety is working.

## 12. Production Notes

Before production:

- use real product images
- add more products per category
- add more outfit templates
- add more fashion rules
- review MongoDB Atlas index status before testing
- add server-side auth for feedback and memory
- add rate limits for Gemini calls
- avoid exposing MongoDB or Gemini secrets to frontend
